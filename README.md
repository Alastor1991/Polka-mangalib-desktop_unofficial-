# Полка

Неофициальный десктопный клиент для сервисов lib.social: MangaLib, SlashLib, RanobeLib, HentaiLib и AnimeLib. Написан на Rust, работает под Linux. Сейчас у Полки временное окно на [iced](https://iced.rs); интерфейс будет переписан на [Slint](https://slint.dev), а вся логика уже живёт в ядре без интерфейса.

> Полка не связана с командой lib.social. Весь контент принадлежит сервису и правообладателям, приложение лишь показывает то, что сайт и так отдаёт пользователю. Платные главы и ранний доступ открываются только тем, кто купил их на своём аккаунте. Обходов нет и не будет.

## Что умеет

В окне сейчас:

- Каталог и поиск по MangaLib, SlashLib, HentaiLib и AnimeLib: все сортировки сайта, включая случайный порядок, и подгрузка при прокрутке. Показываются тайтлы, в которых уже есть главы или серии.
- Страница тайтла: описание, ветки переводов, статус каждой главы (прочитана, скачана, когда откроется ранний доступ).
- Читалка манги: лента для вебтунов и постраничный режим, управление с клавиатуры, место чтения запоминается.
- Скачивание глав на диск с очередью, паузой и докачкой после обрыва. Скачанное читается без сети.
- Экспорт в CBZ по томам, с `ComicInfo.xml`, для любых сторонних читалок.
- Аниме: выбор озвучки, просмотр собственного плеера AnimeLib в [mpv](https://mpv.io) с запоминанием места и пропуском опенинга по разметке команды, скачивание серий с субтитрами. Серии, у которых есть только Kodik, открываются в браузере.
- Синхронизация с аккаунтом: библиотека – это ваши закладки с папками сайта, прочитанные главы и просмотренные серии отмечаются на сайте, место чтения и просмотра попадает в закладку, а «Продолжить» открывает то, на чём вы остановились на другом устройстве. Прочитанное без сети отправится позже.
- Вход один раз. Окно входа lib.social открывается внутри приложения, токен хранится в системном хранилище секретов (gnome-keyring, KWallet) и обновляется сам.
- Зеркала: если один домен API заблокирован в вашей сети, клиент сам переходит на следующий и запоминает рабочий.

Клиент API и ядро уже умеют больше, чем показывает окно. Это появится в интерфейсе на Slint:

- комментарии к тайтлу, главе, отдельной странице главы и серии с ответами любой глубины, голосами, написанием, правкой, жалобами, стикерами и подпиской на новые;
- все фильтры каталога и справочник жанров, тегов и форматов (ядро уже ведёт каталог и держит справочник), главная, ленты обновлений, топы, новости, поиск людей, команд, персонажей, издателей и пользователей;
- всё вокруг тайтла: обложки, статистика, связанные и похожие тайтлы, персонажи, авторы, издатели, франшизы, команды переводчиков, отзывы, своя оценка, лайк главы, оценка перевода, подписки на ветку и озвучку, озвучка манги видео;
- уведомления, профиль и его правка, статистика, история чтения и просмотра, настройки аккаунта, друзья и заявки в друзья, игнор-лист, личные сообщения, подборки, избранное, свои папки закладок и заметки к главам;
- жалобы на пользователей, подборки, отзывы, карточки, темы, главы и серии, сообщения об ошибке в карточке тайтла, справка сайта;
- ранобэ: главы текстом с картинками и номерами абзацев, серверный экспорт книг;
- коллекционные карточки: инвентарь, альбомы, рынок, обмены и история карт.

Подробная таблица того, что на каком уровне готово, – в [docs/roadmap.md](docs/roadmap.md). Чего у Полки пока нет по сравнению с сайтом (мини-чат), перечислено в [docs/api.md](docs/api.md#запросы-сайта-которых-нет-в-клиенте).

## Сборка

Нужны Rust 1.88 или новее и WebKitGTK для окна входа.

```sh
# Arch, CachyOS
sudo pacman -S rust webkit2gtk-4.1 gtk3
# Debian, Ubuntu
sudo apt install cargo libwebkit2gtk-4.1-dev libgtk-3-dev libxkbcommon-dev libwayland-dev

git clone https://github.com/Alastor1991/Polka-mangalib-desktop_unofficial-.git polka
cd polka
cargo build --release
./target/release/polka
```

Для просмотра аниме поставьте mpv (`sudo pacman -S mpv`). Без него можно скачать серию и открыть её в любом плеере.

## Командная строка

```sh
polka                                   # открыть приложение
polka login                             # войти в аккаунт
polka whoami                            # под кем выполнен вход
polka doctor                            # проверить доступ к API, картинкам и видео
polka download mangalib 7965--chainsaw-man 1-10    # скачать главы с 1 по 10
polka download animelib 16133--jujutsu-kaisen-anime 1   # скачать серию
```

`slug` тайтла берётся из адреса на сайте: `mangalib.me/ru/manga/7965--chainsaw-man`.

## Где что лежит

| Что | Где |
|---|---|
| Настройки | `~/.config/polka/config.toml` |
| Библиотека и база | `~/.local/share/polka/` |
| Кэш картинок | `~/.cache/polka/images/` (чистится до лимита из настроек) |
| Токен входа | системное хранилище секретов, без него файл `~/.config/polka/token.json` с правами 0600 |

Пример `config.toml`:

```toml
image_server = "compress"   # compress, main, secondary, download
max_quality = 1080          # предел качества видео
download_concurrency = 4    # сколько картинок качать одновременно
cache_limit_mb = 1024

# Если сервис недоступен из вашей сети:
# interface = "enp4s0"                  # пустить запросы через этот интерфейс
# proxy = "socks5h://127.0.0.1:1080"    # или через прокси
# api_mirrors = ["https://api.cdnlibs.org/api"]   # свои зеркала вместо встроенных

# Что mpv пропускает сам по разметке команды (по умолчанию ничего):
# auto_skip = ["opening", "ending"]   # ещё "ost", "compilation", "splashScreen"

# Свой клиент OAuth, если его выдали разработчики lib.social:
# oauth_client_id = "…"
# oauth_redirect_uri = "…"
```

## Как устроено

```
crates/libsocial   клиент API без интерфейса: все области сервиса, модели, разбор
                   форматированного текста, зеркала, вход OAuth с PKCE,
                   ограничение частоты запросов, повторы, обновление токена
crates/polka-core  ядро без интерфейса: база SQLite, загрузчик, библиотека на диске,
                   синхронизация с аккаунтом, логика экранов, плеер
crates/polka       оболочка: временное окно iced, окно входа, командная строка
```

`libsocial` можно использовать отдельно как библиотеку.

Клиент старается не нагружать сервис: к API не чаще двух запросов в секунду, к серверам картинок не больше заданного числа соединений, при ответе 429 притормаживает вся очередь, а после нескольких сбоев подряд загрузчик делает паузу. Тяжёлый справочник формы каталога запрашивается не чаще раза в 20 минут, как на сайте.

## Разработка

```sh
cargo test                       # модульные тесты, сохранённые ответы API, клиент и загрузчик на мок-сервере
cargo test -p libsocial -- --ignored --test-threads=1   # живые проверки против API, только чтение
```

Отладочный запуск без мыши: `POLKA_DEV_OPEN=mangalib:7965--chainsaw-man:0 polka` открывает тайтл и первую главу в списке, `POLKA_DEV_TAB=library` открывает вкладку.
