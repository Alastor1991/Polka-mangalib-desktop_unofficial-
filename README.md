# Полка

Неофициальный десктопный клиент для сервисов lib.social: MangaLib, SlashLib, HentaiLib и AnimeLib. Написан на Rust, интерфейс на [iced](https://iced.rs). Работает под Linux.

> Полка не связана с командой lib.social. Весь контент принадлежит сервису и правообладателям, приложение лишь показывает то, что сайт и так отдаёт пользователю. Платные главы и ранний доступ открываются только тем, кто купил их на своём аккаунте. Обходов нет и не будет.

## Что умеет

- Каталог и поиск по всем сайтам сети с сортировкой и подгрузкой при прокрутке.
- Страница тайтла: описание, ветки переводов, статус каждой главы (прочитана, скачана, когда откроется ранний доступ).
- Читалка: лента для вебтунов и постраничный режим, управление с клавиатуры, место чтения запоминается.
- Скачивание глав на диск с очередью, паузой и докачкой после обрыва. Скачанное читается без сети.
- Экспорт в CBZ по томам, с `ComicInfo.xml`, для любых сторонних читалок.
- Аниме: выбор озвучки, просмотр собственного плеера AnimeLib в [mpv](https://mpv.io), скачивание серий с субтитрами. Серии, у которых есть только Kodik, открываются в браузере.
- Вход один раз. Окно входа lib.social открывается внутри приложения, токен хранится в системном хранилище секретов (gnome-keyring, KWallet) и обновляется сам.
- Зеркала: если один домен API заблокирован в вашей сети, клиент сам переходит на следующий и запоминает рабочий.

## Сборка

Нужны Rust 1.88 или новее и WebKitGTK для окна входа.

```sh
# Arch, CachyOS
sudo pacman -S rust webkit2gtk-4.1 gtk3
# Debian, Ubuntu
sudo apt install cargo libwebkit2gtk-4.1-dev libgtk-3-dev libxkbcommon-dev libwayland-dev

cargo build --release
./target/release/polka
```

Для просмотра аниме поставьте mpv (`sudo pacman -S mpv`). Без него можно скачать серию и открыть её в любом плеере.

## Командная строка

```sh
polka                                   # открыть приложение
polka login                             # войти в аккаунт
polka whoami                            # под кем выполнен вход
polka doctor                            # проверить доступ к API, картинкам и видео
polka download mangalib 7965--chainsaw-man 1-10    # скачать главы с 1 по 10
polka download animelib 16133--jujutsu-kaisen-anime 1   # скачать серию
```

`slug` тайтла берётся из адреса на сайте: `mangalib.me/ru/manga/7965--chainsaw-man`.

## Где что лежит

| Что | Где |
|---|---|
| Настройки | `~/.config/polka/config.toml` |
| Библиотека и база | `~/.local/share/polka/` |
| Кэш картинок | `~/.cache/polka/images/` (чистится до лимита из настроек) |
| Токен входа | системное хранилище секретов, без него файл `~/.config/polka/token.json` с правами 0600 |

Пример `config.toml`:

```toml
image_server = "compress"   # compress, main, secondary, download
max_quality = 1080          # предел качества видео
download_concurrency = 4    # сколько картинок качать одновременно
cache_limit_mb = 1024

# Если сервис недоступен из вашей сети:
# interface = "enp4s0"                  # пустить запросы через этот интерфейс
# proxy = "socks5h://127.0.0.1:1080"    # или через прокси
# api_mirrors = ["https://api.cdnlibs.org/api"]   # свои зеркала вместо встроенных
```

## Как устроено

```
crates/libsocial   клиент API без интерфейса: модели, зеркала, вход OAuth с PKCE,
                   ограничение частоты запросов, повторы, обновление токена
crates/polka       приложение: база SQLite, загрузчик, библиотека на диске, интерфейс
```

`libsocial` можно использовать отдельно как библиотеку.

Клиент старается не нагружать сервис: к API не чаще двух запросов в секунду, к серверам картинок не больше заданного числа соединений, при ответе 429 притормаживает вся очередь, а после нескольких сбоев подряд загрузчик делает паузу.

## Разработка

```sh
cargo test                       # модульные тесты и тесты на сохранённых ответах API
cargo test -p libsocial --test live -- --ignored --test-threads=1   # живые проверки против API
```

Отладочный запуск без мыши: `POLKA_DEV_OPEN=mangalib:7965--chainsaw-man:0 polka` открывает тайтл и первую главу в списке, `POLKA_DEV_TAB=library` открывает вкладку.
