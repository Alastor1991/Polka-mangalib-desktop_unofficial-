# Руководство пользователя

## Установка

Полка собирается из исходников. Нужны Rust 1.88 или новее и WebKitGTK, на котором работает окно входа.

```sh
# Arch, CachyOS, Manjaro
sudo pacman -S rust webkit2gtk-4.1 gtk3

# Debian, Ubuntu
sudo apt install cargo libwebkit2gtk-4.1-dev libgtk-3-dev libxkbcommon-dev libwayland-dev
```

```sh
git clone https://github.com/Alastor1991/Polka-mangalib-desktop_unofficial-.git polka
cd polka
cargo build --release
```

Готовая программа: `target/release/polka`. Её можно положить в `~/.local/bin`, а ярлык `packaging/polka.desktop` в `~/.local/share/applications`, тогда Полка появится в меню приложений.

Для просмотра аниме поставьте mpv:

```sh
sudo pacman -S mpv        # или sudo apt install mpv
```

## Первый запуск и вход

Без входа доступны каталог, чтение открытых глав и скачивание. Вход нужен для трёх вещей: разделов 18+, глав, купленных на вашем аккаунте, и собственного видеоплеера AnimeLib.

Войти можно двумя способами:

- в приложении: «Настройки» → «Войти»;
- в терминале: `polka login`.

Откроется небольшое окно со страницей входа lib.social. Войдите как обычно и подтвердите доступ. Окно закроется само, а программа запомнит вход. Пароль видит только страница lib.social, Полка получает лишь токен доступа.

Токен хранится в системном хранилище секретов (gnome-keyring, KWallet) и обновляется сам, так что входить заново не придётся. Если хранилища нет, токен лежит в `~/.config/polka/token.json`, и читать этот файл может только ваш пользователь.

Если страница входа в окне не открывается, попробуйте запасной сервер авторизации:

```sh
polka login --mirror 2
```

Выйти: «Настройки» → «Выйти» или `polka logout`.

## Каталог

Вверху выбирается сайт: MangaLib, SlashLib, HentaiLib или AnimeLib. Ниже идут поиск по названию и сортировка. Новые тайтлы подгружаются, когда список прокручен до конца.

Нажмите на обложку, чтобы открыть страницу тайтла.

## Страница тайтла

Здесь описание, жанры, рейтинг и список глав или серий.

Кнопки вверху:

- «В библиотеку» добавляет тайтл во вкладку «Библиотека»;
- «Открыть на сайте» открывает тайтл в браузере;
- «Читать» продолжает с главы, на которой вы остановились, а если вы ещё не читали, начинает с первой;
- «Скачать все» ставит в очередь все доступные главы выбранного перевода;
- «Экспорт CBZ» собирает скачанные главы в архивы CBZ по томам.

Если главу перевели несколько команд, над списком появляется выбор перевода. Список глав и скачивание всегда идут по выбранному переводу.

Что значат пометки у глав:

| Пометка | Значение |
|---|---|
| 🔒 откроется 13.10.2026 | ранний доступ, глава откроется бесплатно в эту дату |
| 🔒 платная | платная глава, не купленная на вашем аккаунте |
| ✓ прочитано | глава дочитана до конца |
| стр. 5/20 | место, где вы остановились |
| ⬇ скачано, ⬇ 40%, в очереди | состояние загрузки |

Кнопка ✓ в строке вручную отмечает главу прочитанной, а ↺ снимает отметку. Порядок списка («сначала новые» или «сначала первые») переключается над ним.

Закрытые главы Полка не открывает и не скачивает. Купленные на вашем аккаунте главы доступны после входа.

## Читалка

Два режима переключаются кнопкой вверху или клавишей M:

- лента: страницы идут подряд, удобно для вебтунов и манхвы;
- страницы: одна страница во всё окно, удобно для манги.

| Клавиша | Действие |
|---|---|
| → , Page Down, пробел | следующая страница (в ленте прокрутка на экран вниз) |
| ← , Page Up, Shift+пробел | предыдущая страница |
| ↓ , ↑ | плавная прокрутка в ленте |
| ] или N | следующая глава |
| [ или P | предыдущая глава |
| M | сменить режим |
| Esc | вернуться к тайтлу |

Место чтения запоминается само. В ленте оно приблизительное, потому что высоту страниц заранее не знает ни программа, ни сайт.

Скачанные главы читаются с диска, без сети. Если страница не загрузилась из сети, под ней будет кнопка «Ещё раз».

## Загрузки

Главы и серии ставятся в очередь кнопкой «Скачать» на странице тайтла. Ход загрузок виден на вкладке «Загрузки»: там же пауза, продолжение и удаление.

Очередь переживает закрытие программы и выключение компьютера: после запуска загрузка продолжится с того места, где остановилась. Недокачанное видео докачивается с места обрыва.

Субтитры серии качаются раньше видео. Если сервер в этот момент сбоит, задание встаёт с ошибкой «субтитры», и «Продолжить» докачает и их, и серию. Если субтитров на сервере просто нет, серия скачается без них.

«Удалить» убирает задание из очереди вместе со скачанными файлами.

Если при запуске окна загрузки уже шли в терминале (`polka download`), окно покажет, что очередь ведёт другой запуск. Когда тот закончит, окно продолжит само.

### Экспорт в CBZ

CBZ – обычный ZIP со страницами. Его открывают почти все читалки комиксов на компьютере и телефоне. Полка собирает по одному файлу на том, кладёт в архив `ComicInfo.xml` с названием, томом и номерами глав и сохраняет всё в `~/.local/share/polka/library/export/<название>/`. В экспорт попадают только главы, скачанные целиком.

## Аниме

На странице аниме над списком серий выбирается озвучка. В списке показаны только команды, у которых есть видео на собственном плеере AnimeLib.

- «Смотреть» открывает серию в mpv с выбранной озвучкой и субтитрами. Скачанная серия играет с диска.
- «Скачать» ставит серию в очередь в качестве, заданном в настройках.
- «Kodik» открывает серию в браузере. Так смотрят серии, у которых есть только плеер Kodik.

Собственный плеер AnimeLib сервис отдаёт только после входа. Без входа «Смотреть» подскажет войти.

Где вы остановились в серии, mpv программе пока не сообщает. Серия помечается начатой при запуске, а просмотренной её отмечает кнопка ✓.

## Библиотека

На вкладке «Библиотека» лежат тайтлы, которые вы добавили, и тайтлы, у которых есть скачанные главы или серии. Она работает без сети: карточка тайтла и обложка хранятся рядом со скачанным. Если сети нет, страница тайтла покажет только скачанное и предупредит об этом.

## Настройки

| Настройка | Что делает |
|---|---|
| Сетевой интерфейс | пускает запросы через указанный интерфейс, например `enp4s0`, в обход VPN |
| Прокси | пускает запросы через прокси, например `socks5h://127.0.0.1:1080` |
| Сервер картинок | `compress` быстрее всего, `main` и `secondary` отдают оригиналы |
| Качество видео не выше | предел для просмотра и скачивания |
| Картинок одновременно | сколько страниц качать параллельно |

Сетевые настройки, сервер картинок и параллельность применяются после перезапуска. Все настройки хранятся в `~/.config/polka/config.toml`, там же можно задать свои зеркала API и размер кэша картинок. Пример есть в [README](../README.md).

## Командная строка

```sh
polka                                       # окно
polka login [--mirror 2 | --browser]        # вход
polka logout                                # выход
polka whoami                                # под кем вход и сколько ещё действует токен
polka doctor                                # проверка доступа к сервису
polka download <сайт> <slug> [от-до]        # скачать главы или серии
```

Сайт: `mangalib`, `slashlib`, `hentailib`, `animelib`. `slug` берётся из адреса тайтла на сайте: в `mangalib.me/ru/manga/7965--chainsaw-man` это `7965--chainsaw-man`. Диапазон задаёт номера глав или серий: `1-10`, `5`, `97.5`.

```sh
polka download mangalib 7965--chainsaw-man 1-10
polka download animelib 16133--jujutsu-kaisen-anime 1-3
```

`polka login --browser` открывает вход в системном браузере. Тогда адрес возврата придётся найти в истории браузера (Ctrl+H, поиск «callback») и вставить в терминал. Этот способ запасной, на случай если встроенное окно не работает.

## Если что-то не работает

Сначала запустите проверку:

```sh
polka doctor
```

Она проверит по очереди API, вход, каталоги всех сайтов, загрузку страницы и плеер AnimeLib и скажет, что именно не работает.

| Симптом | Что делать |
|---|---|
| «API недоступен ни через одно зеркало» | Сервис закрыт для вашей сети. Попробуйте другой выход VPN, а если VPN мешает, пустите Полку мимо него: настройка «Сетевой интерфейс» или переменная `POLKA_INTERFACE=enp4s0`. Можно задать прокси. |
| Окно входа пустое или не открывается | Проверьте, что установлен `webkit2gtk-4.1`. Попробуйте `polka login --mirror 2` или `polka login --browser`. |
| «Сохранённый вход больше не действует» | Сервис отозвал токен, войдите заново. |
| Нет кнопки «Смотреть» с видео, только Kodik | Не выполнен вход, или у серии нет собственного плеера AnimeLib. |
| «Для просмотра нужен mpv» | Установите mpv. |
| Страницы не грузятся, а каталог работает | Смените сервер картинок в настройках. |
| Серия упала с ошибкой «субтитры» | Сервер видео временно не ответил. Нажмите «Продолжить» или «Повторить упавшие», недокачанное видео не потеряется. |
| Загрузки стоят «в очереди» | Если на вкладке написано, что их ведёт другой запуск, закройте его. После нескольких ошибок подряд загрузчик делает паузу до пяти минут, чтобы не перегружать сервис. |

## Где лежат данные и как всё удалить

| Что | Где |
|---|---|
| Настройки | `~/.config/polka/` |
| Библиотека, база, скачанное | `~/.local/share/polka/` |
| Кэш картинок | `~/.cache/polka/` |
| Токен | системное хранилище секретов, запись `polka` |

Чтобы удалить всё:

```sh
polka logout
rm -rf ~/.config/polka ~/.local/share/polka ~/.cache/polka
```

Перед этим убедитесь, что скачанное вам больше не нужно: команда удаляет и библиотеку.
